# Chrome Web Store screenshots

Reviewed upload-ready screenshots live in `final/`. Source captures and local
crop/resize intermediates are intentionally ignored.

Chrome Web Store screenshot requirements used here:

- 1280 x 800 or 640 x 400 pixels
- JPEG or 24-bit PNG without an alpha channel
- UI shown by the real extension on controlled original sample text

`01-reading-sample-1280x800.png` is an RGB 1280 x 800 PNG. Its controlled page
source is `docs/demo/reading-sample/index.md`.
