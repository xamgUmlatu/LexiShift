Recommended capture guidance:

- Use PNG.
- Keep width around `1600px` for desktop captures when possible.
- Capture mobile-width views separately when a flow has a meaningfully different layout.
- Blur/redact any personal paths, account names, email addresses, or tokens.
- Prefer consistent zoom/font scale across all screenshots.
- Keep OS warning screenshots focused on the warning itself; avoid including unrelated desktop content.
