# LexiShift Support

The beta support route is intentionally lightweight while installer downloads
are still being prepared.

## Access And Feedback

- If you were invited directly, reply through the invite thread first for the
  private download link.
- If you need beta access and do not have an invite thread, open an issue in the
  [LexiShift GitHub repository](https://github.com/xamgUmlatu/LexiShift/issues)
  and say which platform you can test.
- For bug reports, use the same route and include the details below.

## What To Include

<div class="support-grid">
  <article class="support-card">
    <h3>Environment</h3>
    <p>Operating system, app version, install method, and whether this is a fresh install or an update.</p>
  </article>
  <article class="support-card">
    <h3>Steps</h3>
    <p>What you clicked or changed, what you expected, and what happened instead.</p>
  </article>
  <article class="support-card">
    <h3>Privacy</h3>
    <p>Remove private text from screenshots and avoid sharing logs or local data files unless asked.</p>
  </article>
</div>

## Known Beta Boundaries

- Installer links are not public until the first beta artifact is uploaded and
  the beta gate is ready.
- Manual updates are expected during beta.
- Account sync and cloud backup are not part of the current beta scope.
- Hosted resource downloads must stay inside the project's licensing and
  distribution rules.
