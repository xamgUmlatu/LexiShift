# LexiShift Getting Started (Placeholder)

This is a placeholder guide page for the GUI app onboarding flow.

## What the GUI app is for

- Manage profiles.
- Manage rulesets linked to profiles.
- Create rules manually.
- Generate rules in bulk from synonym sources.
- Export/import profile and ruleset data.

## Core flow (recommended)

1. Create or import a profile.
2. Create or link a ruleset.
3. Add rules manually, or use Synonym Bulk Add.
4. Save ruleset.
5. Use the extension or BetterDiscord plugin to apply rules in real usage.

## SRS note

SRS mode is used in the extension/plugin surfaces.
The GUI app is primarily your management and authoring workspace.
